Club crests go in this folder.

Save each official crest as a PNG with exactly these names and the dashboard (index.html) shows it
automatically in place of the lettered badge:

  sporting-cp.png
  manchester-united.png
  real-madrid.png
  juventus.png
  al-nassr.png
  portugal.png      (national team crest)

Use the images from each club's or federation's official site. Crests are trademarks of their owners,
so check the usage terms before publishing the dashboard publicly.
